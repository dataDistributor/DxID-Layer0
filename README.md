# DxID / Layer 0

**DxID/Layer0** is an early prototype for a modular, identity-first Layer 0 blockchain designed with zk-STARK-based decentralized identity in mind. The project prioritizes quantum-proof security, peer-to-peer networking, and sovereign authentication across interoperable ecosystems.

### 🧩 Project Vision
Our goal is to provide a foundational blockchain layer where identity is the core primitive — allowing individuals, organizations, and systems to verify and authenticate securely without traditional centralized authorities.

- Identity-first Layer 0 chain
- zk-STARK-based cryptographic verification (quantum-proof)
- Peer-to-peer network (libp2p) with future mDNS discovery
- C++ and Web3-compatible frontend modules
- Rust-based backend with modular crate system

### 🗂️ Project Structure

- **docs/** – Documentation, whitepapers, and research papers  
- **dapp-cpp/** – C++ GUI for decentralized identity (FFI to Rust)  
- **smart-contracts/** – Identity and governance contracts (Rust)  
- **scripts/** – Deployment and utility scripts  
- **.github/** – GitHub Actions CI/CD workflows  
- **.vscode/** – Dev environment settings  
- **src/** – Rust source code (modular blockchain engine)  
  - **layer0-core/** – Core blockchain server logic  
  - **zk-verification/** – zk-STARK identity proof engine
